# محاسبك — موقع خدمة المحاسبة والضريبة

موقع Next.js (App Router) + TypeScript + Tailwind CSS، صفحة رئيسية عربية بالكامل (RTL) لخدمة محاسبة وضريبة شهرية عن بُعد تستهدف البوفيهات والمطاعم والكافيهات والمتاجر الإلكترونية والمنشآت الصغيرة والمتوسطة في السعودية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## البناء للإنتاج

```bash
npm run build
npm run start
```

## النشر على Vercel

1. ارفع المشروع إلى مستودع GitHub (أو GitLab/Bitbucket).
2. ادخل إلى https://vercel.com → New Project → اختر المستودع.
3. Vercel يكتشف أنه مشروع Next.js تلقائيًا؛ اضغط Deploy بدون أي إعداد إضافي.
4. بعد النشر، اربط نطاقك الخاص من Project Settings → Domains.

بديل سريع عبر الطرفية (بعد تثبيت Vercel CLI بـ `npm i -g vercel`):

```bash
vercel
```

## ملاحظة مهمة عن نموذج التواصل

النموذج حاليًا **لا يرسل البيانات إلى خادم أو قاعدة بيانات** — عند الإرسال يفتح واتساب تلقائيًا برسالة تحتوي ملخص الطلب، ويعرض رسالة تأكيد للزائر. هذا كافٍ للانطلاق السريع، لكن قبل الإطلاق الفعلي يُفضّل ربطه بأحد الخيارات التالية حتى لا تفوتك أي طلبات لو ما فتح واتساب تلقائيًا عند الزائر (بعض متصفحات الجوال تمنع الفتح التلقائي أحيانًا):
- خدمة بريد مثل Resend أو EmailJS لإرسال الطلب كإيميل.
- Google Sheets عبر Apps Script أو أداة مثل Formspree.
- قاعدة بيانات بسيطة (مثل Supabase) لحفظ الطلبات ومراجعتها لاحقًا.

موضع الكود المطلوب تعديله موجود في `src/components/ContactForm.tsx` داخل دالة `handleSubmit` (فيه تعليق يوضح بالضبط أين تضيف الاستدعاء).

## قائمة تجهيزات قبل الإطلاق الفعلي

1. استبدال رقم واتساب المؤقت (966500000000) برقمك الحقيقي في `src/lib/site-config.ts`.
2. إضافة بريدك الإلكتروني الحقيقي في نفس الملف.
3. تحديث `siteUrl` بالنطاق الفعلي بعد شرائه وربطه.
4. إضافة شعارك الحقيقي بدل الأيقونة المؤقتة.
5. ربط نموذج التواصل بخدمة إرسال فعلية (راجع الملاحظة أعلاه).
6. مراجعة صفحتي سياسة الخصوصية والشروط والأحكام مع مختص قانوني.
7. تعديل الأسعار والمزايا إن تغيّرت.
8. إضافة صورة Open Graph مخصصة (اختياري) بوضع ملف `opengraph-image.png` داخل `src/app/`.
9. اختبار الموقع فعليًا من الجوال بعد النشر (الموقع مبني أصلًا Mobile First).
10. تفعيل نطاق مخصص وربط شهادة SSL (تلقائي عبر Vercel).
