]# مِزارو (Mizaro) — موقع خدمات المحاسبة والتجارة الإلكترونية

موقع Next.js (App Router) + TypeScript + Tailwind CSS، صفحة رئيسية عربية بالكامل (RTL) لخدمات محاسبة وضريبة شهرية عن بُعد، بالإضافة لخدمات التجارة الإلكترونية، تستهدف المنشآت الصغيرة والمتوسطة والمتاجر الإلكترونية في السعودية.

المحتوى (الأسعار، رقم واتساب، البريد الإلكتروني، الأسئلة الشائعة) قابل للتعديل مباشرة عبر لوحة تحكم Sanity CMS المدمجة على `/studio`، بدون الحاجة لتعديل الكود.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## البناء للإنتاج

```bash
npm run build
npm run start
```

## النشر على Vercel

1. المشروع مرفوع على مستودع GitHub ومربوط بمشروع Vercel، وأي دفع (push) لفرع `main` ينشر نسخة جديدة تلقائيًا.
2. متغيرات البيئة المطلوبة في إعدادات Vercel (Project Settings → Environment Variables):
   - `NEXT_PUBLIC_SANITY_PROJECT_ID`
   - `NEXT_PUBLIC_SANITY_DATASET`

## لوحة تحرير المحتوى (Sanity Studio)

متاحة على `/studio` من نفس نطاق الموقع. تحتاج تسجيل دخول بحساب Sanity له صلاحية على المشروع. من خلالها تقدر تعدّل:

- إعدادات الموقع العامة (اسم الشركة، واتساب، البريد الإلكتروني)
- باقات المحاسبة والضريبة
- باقات التجارة الإلكترونية
- الأسئلة الشائعة

الموقع يعرض قيم افتراضية احتياطية (fallback) من `src/lib/site-config.ts` في حال عدم توفر اتصال بـ Sanity، فما ينكسر أبدًا حتى لو صار خلل مؤقت بالاتصال.

## أماكن التعديل الأساسية بالكود

| ما تريد تغييره | أين تجده |
|---|---|
| القيم الاحتياطية الافتراضية (fallback) | `src/lib/site-config.ts` |
| طبقة جلب البيانات من Sanity | `src/lib/sanity-data.ts` |
| مخططات محتوى Sanity (Schemas) | `src/sanity/schemaTypes/` |
| الشعار | `src/components/Header.tsx` و `src/components/Footer.tsx` |
| نصوص Hero (العنوان الرئيسي) | `src/components/Hero.tsx` |
| بطاقات الخدمات | `src/components/Services.tsx` و `src/components/EcommerceServices.tsx` |
| نموذج طلب الخدمة | `src/components/UnifiedContactForm.tsx` |
| سياسة الخصوصية / الشروط والأحكام | `src/app/privacy/page.tsx` و `src/app/terms/page.tsx` (صياغة أولية عامة — راجعها قانونيًا) |
| عنوان ووصف SEO / Open Graph | `src/app/layout.tsx` |

## ملاحظة عن نموذج التواصل

النموذج حاليًا **لا يرسل البيانات إلى خادم أو قاعدة بيانات** — عند الإرسال يفتح واتساب تلقائيًا برسالة تحتوي ملخص الطلب، ويعرض رسالة تأكيد للزائر. قبل الإطلاق الفعلي يُفضّل ربطه بأحد الخيارات التالية حتى لا تفوتك أي طلبات لو ما فتح واتساب تلقائيًا عند الزائر:

- خدمة بريد مثل Resend أو EmailJS لإرسال الطلب كإيميل.
- Google Sheets عبر Apps Script أو أداة مثل Formspree.
- قاعدة بيانات بسيطة (مثل Supabase) لحفظ الطلبات ومراجعتها لاحقًا.

موضع الكود المطلوب تعديله موجود في `src/components/UnifiedContactForm.tsx` داخل دالة `handleSubmit`.

## قائمة تجهيزات قبل الإطلاق الفعلي

1. تحديث رقم واتساب والبريد الإلكتروني الحقيقيين من لوحة `/studio` (إعدادات الموقع العامة).
2. إضافة نطاق مخصص وربط شهادة SSL (تلقائي عبر Vercel).
3. ربط نموذج التواصل بخدمة إرسال فعلية (راجع الملاحظة أعلاه).
4. مراجعة صفحتي سياسة الخصوصية والشروط والأحكام مع مختص قانوني.
5. إضافة صورة Open Graph مخصصة (اختياري) بوضع ملف `opengraph-image.png` داخل `src/app/`.
6. اختبار الموقع فعليًا من الجوال بعد النشر (الموقع مبني أصلًا Mobile First).
